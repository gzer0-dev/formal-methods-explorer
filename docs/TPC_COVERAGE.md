# Roscoe『The Theory and Practice of Concurrency』（TPC）の範囲と、このサイトの対応

ユーザーの依頼（2026-11-24）: 「これの内容も含めて」と TPC（Prentice-Hall 1997、2005 年改訂版の PDF）を渡された。
本の範囲もサイトで学べるようにする。**本文・図・例・名前付きプロセスの定義は写さない**（PDF は個人の参照用として配られている）。
例は自作か古典の問題（交互ビット・Needham–Schroeder・食事する哲学者など）にし、facts に本の章と節を書き添えるだけにする。

凡例: ある＝既存のレッスンで扱っている（facts に節を書き足す）／足す＝新しいレッスン／載せない＝理由つきで外す
